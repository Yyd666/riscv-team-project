# 首批正确性语料

各 C 样例从 stdin 读取数据，输出格式为一个十进制整数及 LF 换行。样例无时间、随机数、文件或网络依赖。`kernel` 保留 `noinline` 属性以便在优化后定位函数；计算数据由运行时输入提供。

- `sum_u32`：`n` 后接 n 个 uint32，n 为 0..64；结果按模 2^32 求和。
- `dot_i32`：`n` 后接第一组 n 个整数，再接第二组 n 个整数；n 为 0..64，元素为 -10000..10000，返回 int64 点积。
- `threshold_count`：`n threshold` 后接 n 个整数；n 为 0..64，阈值及元素为 -10000..10000，返回大于等于阈值的个数。

注册表及用例顺序以 `manifest.json` 为准，每个程序包含三组输入。读取失败或登记范围内的参数检查失败时，程序返回退出码 2。首版正确性测试使用已登记的有效输入，输入解析范围限定为上述格式。

预期输出依据数学定义独立计算。基础检查核对输入约束、预期值及行尾；C 编译与执行单独验证。RISC-V 工具链配置与执行步骤见 `docs/BASELINE.md`。

当前语料规模小，适合编译/运行/分析链路验收，不适合统计运行速度。增加语料应更新 corpus_version、独立预期值和接口列表 mock；扩展性能语料时另行说明规模与设计依据。
