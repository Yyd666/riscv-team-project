# 首批正确性语料

每个 C 文件从 stdin 读取数据，结果输出为一个十进制整数和 LF。没有时间、随机数、文件或网络依赖。`kernel` 保留 `noinline` 以便在优化后定位函数；数据由运行时输入提供，避免整个计算被常量折叠。

- `sum_u32`：`n` 后接 n 个 uint32，n 为 0..64；结果按模 2^32 求和。
- `dot_i32`：`n` 后接第一组 n 个整数，再接第二组 n 个整数；n 为 0..64，元素为 -10000..10000，返回 int64 点积。
- `threshold_count`：`n threshold` 后接 n 个整数；n 为 0..64，阈值及元素为 -10000..10000，返回大于等于阈值的个数。

注册表及用例顺序以 `manifest.json` 为准，每个程序三个输入。无效读取/超界输入以退出码 2 失败；首版只将注册的有效输入作为正确性测试。这里不是通用的恶意输入解析器。

预期输出由数学定义独立计算，不从某个编译档位自动生成。基础检查会核对输入约束、预期值和行尾；它不编译 C。`docs/BASELINE.md` 提供主动进行 RISC-V 编译运行的步骤。

当前语料规模小，适合编译/运行/分析链路验收，不适合统计运行速度。增加语料应更新 corpus_version、独立预期值和接口列表 mock；扩展性能语料时另行说明规模与设计依据。
