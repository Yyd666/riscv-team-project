# 首版验收清单

本清单用于首版业务功能验收。验收状态依据实际执行记录更新，公共配置与样例检查单独记录。

## 工程与功能

- [ ] 按 README 与环境配置文档可完成服务安装及启动，依赖锁文件与操作命令齐全。
- [ ] 固定 Linux 工具链能生成 RISC-V ELF，`readelf` 检查架构与属性符合基线。
- [ ] 3 个程序 × 3 个输入 × 3 个编译档位，共 27 次运行全部有原始记录。
- [ ] 每次输出、stderr 和退出码与登记期望逐字节一致；独立错误样例能触发失败。
- [ ] 编译错误、工具缺失、运行超时及输出超限场景均返回明确信息，并完成进程及资源清理。
- [ ] 静态指标与保存的 binutils 输出可手动复核，解析失败不得给出成功数字。
- [ ] 请求/结果遵循 API 契约，失败方案不参与推荐；无通过方案显示无推荐。
- [ ] 前后端完成 API 联调，mock 模式显示演示标识，API 模式失败时展示错误。
- [ ] 同一输入连续执行两次，输出、指令计数和体积一致；宿主时间允许变化。
- [ ] JSON 与 Markdown 来自同一实验记录；包含命令、环境、配置和输入/源码哈希。

## 结论与比赛材料

- [ ] 正式比较包含 O2、Os；区分文件大小、节大小、kernel 指令数与宿主时间。
- [ ] 体积、执行时间、周期及能耗结论均具有对应的测量依据。
- [ ] 说明现有工作与第三方工具的边界、自研部分及当前局限。
- [ ] 演示包含实际成功案例、失败案例、汇编差异及原始报告位置。
- [ ] 在不同机器或独立 Linux 环境完成复现，并记录环境与结果差异。
- [ ] 官方材料、资格、截止时刻、指导教师/成员署名、原创与引用要求经队伍核对。

## 每个 PR 的验证记录

验证记录包含命令、运行环境、退出状态、涉及用例、报告路径及未验证项。截图作为补充材料，原始数据应单独保留。公共基线的验证记录见 `docs/STATUS.md`；后续实验按独立记录归档，保留历史结论。
