# 首版验收清单

本清单用于首版业务功能验收。CLI、真实 RISC-V 实测和 JSON/Markdown 报告是必需项；API 和前端是可选增强项。验收状态依据实际执行记录更新，公共配置与样例检查单独记录。

## 工程与功能

- [ ] Linux/WSL2 或等效 Linux 环境已记录，工具链、sysroot、binutils 和 QEMU 版本齐全。
- [ ] 固定 Linux 工具链能生成 RISC-V ELF，readelf 检查架构与属性符合基线。
- [ ] 3 个程序 × 3 个输入 × 3 个编译档位，共 27 次运行全部有原始记录。
- [ ] 每次输出、stderr 和退出码与登记期望逐字节一致；独立错误样例能触发失败。
- [ ] 编译错误、工具缺失、运行超时及输出超限场景均返回明确信息，并完成进程及资源清理。
- [ ] 静态指标与保存的 binutils 输出可手动复核，解析失败不得给出成功数字。
- [ ] 请求/结果遵循 API 契约，失败方案不参与推荐；无通过方案显示无推荐。
- [ ] CLI 可从样例选择开始完成编译、运行、校验、分析和推荐。
- [ ] JSON 与 Markdown 报告来自同一实验记录；包含命令、环境、配置和输入/源码哈希。
- [ ] API 联调和前端展示（可选）若未完成，不影响 CLI、实测和报告验收。
- [ ] 同一输入连续执行两次，输出、指令计数和体积一致；宿主时间允许变化。

## 结论与比赛材料

- [ ] 正式比较包含 O2、Os；区分文件大小、节大小、kernel 指令数与宿主时间。
- [ ] 宿主 wall_time_ms 仅作诊断，不用于性能排名或性能提升结论。
- [ ] 报告明确静态指令数不等于动态执行数量，.text 受静态链接影响，QEMU 宿主时间不等于目标处理器性能。
- [ ] 结论限定在登记语料、固定输入和实际工具链环境，不外推到一般 C 程序。
- [ ] 说明现有工作与第三方工具的边界、自研部分及当前局限。
- [ ] 演示包含实际成功案例、失败案例、汇编差异及原始报告位置。
- [ ] 官方材料、资格、截止时刻、指导教师/成员署名、原创与引用要求经队伍核对。

验证记录包含命令、运行环境、退出状态、涉及用例、报告路径及未验证项。截图作为补充材料，原始数据应单独保留。mock 只能用于界面开发和联调，不能代替真实 RISC-V 编译、QEMU 执行和实测记录。公共基线的验证记录见 docs/STATUS.md；后续实验按独立记录归档，保留历史结论。
