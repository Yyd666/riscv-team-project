# 独立复核记录

该文件记录 M2 的人工复核门槛。自动化测试和同一开发者的自检不计为第二位独立复核。

## 已准备证据

- `evaluation/corpus.json`：开发 6 个、留出 6 个程序，按家族与来源隔离，含源码 SHA-256。
- `scripts/freeze_evaluation_corpus.py`：独立 oracle 和冻结清单校验。
- WSL2 真实评估：12 个程序、24 个 O2→候选比较对；字节重建精确率、R001 验证率和 R002 覆盖率均为 1.0。
- `scripts/run_attribution_negatives.py`：5 类真实 ELF 负例均返回 `analysis_error`。
