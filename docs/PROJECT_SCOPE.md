# 项目范围与约束 v0.3

建立日期：2026-10-24，工作时区 Asia/Shanghai。

## 项目定义

项目名称：RISC-V OptiPilot。项目面向 RV64GC 程序开发与教学场景，提供正确性门控、目标代码分析、有限候选配置推荐和可复现实验记录。

初稿只比较现有 GCC 的 O0、O2、Os 三种优化档位。这里的“有限候选配置推荐”是对登记配置的工程化比较，不表述为自研编译优化算法。

## 首稿交付目标

2026-11-08 前交付一个可演示的纯软件 MVP：

1. 从注册语料选择一个单文件 C 程序，读取固定输入，不接受任意上传或 shell 参数；
2. 使用 O0、O2、Os 三种登记配置编译为 RV64GC / LP64D Linux 静态 ELF；
3. 使用 QEMU 执行全部登记用例，校验 stdout、stderr 和退出码；
4. 记录编译失败、运行超时、输出不符和工具缺失等失败原因；
5. 分析 ELF 文件、.text、kernel 函数机器码和静态指令组成；
6. 仅在全部用例通过的配置中，按 .text 静态代码体积给出推荐；
7. 生成契约一致的 JSON 与 Markdown 实验报告，保留命令、版本、哈希和原始运行结果；
8. 通过 CLI 或前端完成一条可录制的演示流程。

## 核心创新

- 正确性门控：配置必须通过全部登记用例后才参与推荐；
- 可解释分析：用指标变化、函数反汇编和失败原因解释配置差异；
- 可复现推荐：源码、输入、配置、工具版本和输出均保存哈希。

这些机制构成流程和工具集成层面的创新。当前不宣称自研编译器或通用最优编译器。

## 指标边界

宿主 wall_time_ms 仅用于超时和执行异常诊断，不进入 Pareto 比较，不用于宣称性能提升。动态指令数、目标周期、能耗和硬件性能不属于初稿已完成结论。

## 范围限制

首稿不包含自研 CPU、自研编译器、完整 ISA 仿真器、RV32/RVV、多线程、浮点精度优化、AI 源码改写、任意用户代码执行、公网多人服务、账户、数据库和硬件验证。

## 后续版本

编译引擎实现并建立独立评估集后，才评估新增候选参数或策略搜索。届时必须新增决策记录，提升 baseline 版本，同步检查脚本、Schema、mock、报告和验证证据。
