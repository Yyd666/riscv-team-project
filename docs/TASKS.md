## 交付优先级

首稿必须完成真实 Linux/WSL2 工具链、RISC-V 交叉编译、QEMU 执行、输出校验、静态分析、CLI 和 JSON/Markdown 报告。FastAPI 和前端用于改善交互体验，属于可选增强项，不得成为 CLI 交付的前置条件。

## 环境故障处理

mock 只能支持界面开发和接口联调，不能替代首稿所需的 RISC-V 编译、QEMU 执行和实测记录。若本机环境失败，应切换到另一台 Ubuntu/WSL2 主机或经批准的 Linux 云环境，并记录工具版本和环境差异；若所有可用环境均不可用，项目必须标明核心实测未完成，不能以 mock 宣称交付完成。
