## 降级策略

如果前端或 FastAPI 影响核心流程，初稿保留可复现 CLI 和静态报告。任何候选参数扩展都不得先于新的决策记录、版本变更和检查脚本同步。

## 任务状态管理

每项任务指定主负责人，可登记协作成员。完成时关联提交或 PR，附检查结果及证据位置，并更新 docs/STATUS.md。
