# 官方参赛材料核对记录

## 官方页面与快照

页面：[CIE 全国 RISC-V 高水平创新及应用大赛](https://rv.cie.org.cn/)，高校赛道详情入口为 [direction?id=5](https://rv.cie.org.cn/direction?id=5)。本记录于 2026-10-28 核对，页面内容和时间安排可能继续更新；提交前应再次打开官方页面保存截图或 PDF，并记录访问时间。

官方页面当前说明高校赛道主要面向国内高等院校在读学生，包括相关科研团队、兴趣小组和爱好者。参赛团队可以是个人或单位；个人组成的团队须指定牵头人，单位组成的团队须指定牵头单位，牵头人/牵头单位须用真实信息注册。每位参赛代表只能代表一个团队，报名截止后不可更改参赛代表。

项目要求每个项目限报一个赛题，项目名称和主要内容在后续更新中不能改变。团队对提交信息的真实性、知识产权和合规性负责。报名通过大赛网站免费在线完成，需按方向、赛道和赛题提交说明文档和演示视频；材料若提交到开源项目，说明文档应附相关 PR/MR。

## 团队待核对项

以下信息不能从仓库或公开页面推断，必须由团队在报名系统和学校信息中确认：

- 团队名称、牵头人/牵头单位、每位代表的真实注册账号；
- 所有代表是否为国内高校在读学生，且没有代表参加第二个团队；
- 选择的比赛方向、高校赛道和唯一赛题；
- 报名是否已完成、报名时间、报名回执和截止前可更新状态；
- 项目说明文档、演示视频、仓库地址、PR/MR 链接和知识产权声明；
- 署名顺序、指导教师或单位信息，以及官方要求的其他字段。

当前这些项目证据均未进入仓库，不能把“项目是开源仓库”写成“已完成官方报名”，也不能代团队填写或猜测真实身份。提交前应将回执、官方材料清单和最终视频哈希存入团队可访问的材料包；凭据和个人敏感信息不提交到 Git。
